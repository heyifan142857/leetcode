# 排序算法分类

这里按照排序过程中采用的主要操作进行分类。`n` 表示元素个数；基数排序中，
`d` 表示处理的数位数，`r` 表示每一位的基数。

| 分类 | 算法 | 最好时间 | 平均时间 | 最坏时间 | 额外空间 | 稳定性 |
| --- | --- | --- | --- | --- | --- | --- |
| 插入排序 | 直接插入排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 插入排序 | 折半插入排序 | O(n log n) | O(n²) | O(n²) | O(1) | 稳定 |
| 插入排序 | 希尔排序（折半增量） | O(n log n) | 取决于增量序列 | O(n²) | O(1) | 不稳定 |
| 交换排序 | 冒泡排序 | O(n) | O(n²) | O(n²) | O(1) | 稳定 |
| 交换排序 | 快速排序 | O(n log n) | O(n log n) | O(n²) | 平均 O(log n) | 不稳定 |
| 选择排序 | 简单选择排序 | O(n²) | O(n²) | O(n²) | O(1) | 不稳定 |
| 选择排序 | 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 归并排序 | 归并排序 | O(n log n) | O(n log n) | O(n log n) | O(n) | 稳定 |
| 分配排序 | 基数排序（LSD） | O(d(n + r)) | O(d(n + r)) | O(d(n + r)) | O(n + r) | 稳定 |

## 目录

- `insertion/`：直接插入排序、折半插入排序、希尔排序
- `exchange/`：冒泡排序、快速排序
- `selection/`：简单选择排序、堆排序
- `merge/`：归并排序（通常单独列为一类）
- `distribution/`：基数排序等分配排序（非比较排序）

希尔排序的复杂度与增量序列密切相关，表中针对本仓库采用的折半增量
`n/2, n/4, ..., 1` 给出容易确认的最好与最坏界。折半插入排序虽然减少了
关键字比较次数，但移动元素的次数没有减少，所以平均和最坏时间仍为 O(n²)。
